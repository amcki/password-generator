# Password Generator

A simple command-line password generator written in Python. Enter how long you want your password to be, and it creates a random one using letters, numbers, and symbols.

## Features

- Generates random passwords of any length
- Uses uppercase letters, lowercase letters, numbers, and symbols
- Simple, beginner-friendly code

## Requirements

- Python 3.6 or higher

No external libraries needed.

## How to Run

1. Clone this repository:
   ```
   git clone https://github.com/amcki/password-generator.git
   ```
2. Navigate into the project folder:
   ```
   cd password-generator
   ```
3. Run the program:
   ```
   python password_generator.py
   ```
   (On Mac/Linux you may need to use `python3 password_generator.py`)

## Example

```
=== Password Generator ===
How long should the password be? 12
Your password is: k7#Qm!x2Lp@9
```
